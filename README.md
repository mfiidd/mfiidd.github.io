# mfiidd.github.io

Landing page for the [MFIIDD](https://mfiidd.github.io/mfiidd/) short course
organisation. It exists so that `mfiidd.github.io` points somewhere useful
rather than returning a 404, and signposts the current course.

The course materials themselves live in
[mfiidd/mfiidd](https://github.com/mfiidd/mfiidd).

Served by GitHub Pages from `main`. Editing `index.html` and pushing is the
whole workflow — there is no build step.
